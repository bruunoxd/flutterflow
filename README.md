💰 App de Finanças Pessoais
Este é um aplicativo de gestão financeira pessoal desenvolvido em FlutterFlow, utilizando Supabase como backend. O app permite que usuários registrem e acompanhem suas entradas, saídas e saldo total, além de editar seus lançamentos de forma prática e visual.

🧩 Funcionalidades
✅ Registro de transações financeiras (entradas e saídas)

📊 Visualização de saldo total, entradas e saídas

✏️ Edição dos registros diretamente na interface

👤 Visualização e edição do perfil do usuário

📁 Integração com Supabase (auth e banco de dados)

📱 Design responsivo com suporte para diferentes tamanhos de tela
